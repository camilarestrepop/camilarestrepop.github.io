# ============================================================================
#  HOW TO ADD A COLLECTION OR A RUNWAY SHOW
#  (Como anadir una coleccion o una pasarela)
# ============================================================================
#
#  1. Copy this whole folder. (Copia toda esta carpeta.)
#  2. Put the copy inside  collections/  for a collection, or inside
#     runways/  for a runway show. Give it a short lowercase name with dashes,
#     for example  rayito-de-sol
#     (Ponla dentro de collections/ o de runways/.)
#  3. Upload the photos into that same folder, named 01.jpg, 02.jpg, 03.jpg...
#     The one named 01 is the cover. With no photos at all the page politely
#     says "coming soon".
#     (Sin fotos, la pagina dice "muy pronto".)
#  4. Edit the lines below. The lines with a colon are the settings; everything
#     from the first line that is not one of them is your description.
#     (Todo lo que no es uno de esos ajustes es ya la descripcion.)
#
#  Folders whose name starts with _ are never published.
#  (Las carpetas que empiezan con _ nunca se publican.)
# ============================================================================

# Optional. A video to show under the photos. There are two ways:
#
#   1. Drop a file called  video.mp4  into this same folder. video.mov and

#      through the browser, so a long video needs way 2.
#      (Sube un archivo llamado video.mp4 a esta misma carpeta. Maximo 25 MB.)
#
#   2. Or put the video on YouTube, Vimeo or Instagram, copy the address from
#      the bar at the top of the browser -- the ordinary one, not an "embed
#      code" -- and paste it on the line below.
#      (O pega aqui la direccion normal de YouTube, Vimeo o Instagram.)
#
